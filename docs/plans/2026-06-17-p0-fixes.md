```rust
    stdout: Mutex<BufReader<ChildStdout>>,
```


## Task 5: Length-Prefix Framing (ML-P0-003)

**Files:**
- Modify: `src-tauri/sam3_bridge.py`
- Modify: `src-tauri/src/sam3_engine.rs`

**Step 1: Design 4-byte LE length header protocol**

Python sends:
```python
payload = json.dumps(response).encode('utf-8')
header = struct.pack('<I', len(payload))
sys.stdout.buffer.write(header + payload)
sys.stdout.buffer.flush()
```

Rust receives:
```rust
fn read_length_prefix<R: Read>(reader: &mut R) -> Result<Vec<u8>> {
    let mut header = [0u8; 4];
    reader.read_exact(&mut header)?;
    let len = u32::from_le_bytes(header) as usize;
    let mut buf = vec![0u8; len];
    reader.read_exact(&mut buf)?;
    Ok(buf)
}
```

**Step 2: Implement in Python bridge**

Modify the main loop in `sam3_bridge.py` to use length-prefix framing.

**Step 3: Implement in Rust engine**

Modify `sam3_engine.rs` to use `read_length_prefix` instead of `read_line`.

**Step 4: Redirect Python stdout to prevent accidental prints**

In `sam3_bridge.py` at startup:
